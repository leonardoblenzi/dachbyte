# Volt Stock Desktop

Espaco reservado para a aplicacao Tauri + React, voltada a:

- leitores USB/Bluetooth em modo teclado HID;
- impressao termica ZPL/TSPL/ESC-POS;
- cache operacional local;
- fila local de impressao e reenvio.

A implementacao deve consumir a mesma API versionada de `apps/api`.
