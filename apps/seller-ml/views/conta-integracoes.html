Como configurar no MarkFlow

Envie estas instrucoes ao dev do MarkFlow para criar a fila Davantti e devolver as entregas de marketing.

1. Healthcheck para teste de conexao

O MarkFlow deve expor um endpoint autenticado para o Davantti validar URL e token.

GET /api/integrations/davantti/health Header esperado: Authorization: Bearer <token cadastrado no Davantti>
2. Receber tarefas do Davantti

Quando o lote exigir Marketing, o Davantti enviara a conta ML de origem, o lote e os MLBs.

POST /api/integrations/davantti/tasks

3. Responder criacao da tarefa

O MarkFlow deve retornar o ID/link externo para o Davantti manter o vinculo.

{
  "success": true,

      "davantti_task_id": 123,

      "external_url": "https://markflow.app/tasks/MF-152973",
      "status": "todo"
    }
  ]
}

Como configurar no Trello

Conecte via API key + token para habilitar importacao de cards/listas no modulo Estrategicos.

1. Gere credenciais no Trello

Crie a chave e o token da conta que possui acesso aos boards que serao importados.

Use a mesma conta/usuario que sua equipe usa no dia a dia para evitar bloqueio de permissao.
2. Salve e teste a conexao

Com status ativo, chave e token preenchidos, use "Testar conexao". O Davantti valida a conta em /members/me.

3. Importacao na tela Estrategicos

Depois da conexao ativa, o admin podera importar boards/listas para criar lotes e distribuir por setor.

A configuracao do Trello vale para toda a empresa (todas as contas ML vinculadas).
