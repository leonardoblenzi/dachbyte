Compatibilidade Protocolo TLS
Utilizamos protocolos criptográficos do TLS versão 1.2 (e superiores) conforme os padrões atuais de segurança da informação e boas práticas na proteção de dados.
MagaZord REST API
As APIs REST do MagaZord permitem com que você construa integrações e extenda as capacidades da plataforma MagaZord.
Política de CORS
As APIS REST do MagaZord são construídas seguindo o modelo de restrição same-origin no qual o CORS (Cross-Origin Resource Sharing) é restrito por origem.De maneira prática a aplicação dessa política impede com que páginas web consumam as APIs da plataforma por meio de Javascript em contexto frontend.A aplicação dessa política é utilizada como uma camada base de segurança de modo a evitar consumos inadequados das APIs do MagaZord.

Editar Características do Produto
Observações
Aqui vale destacar que as características do produto são associadas confome as categorias relacionadas a ele. Portanto, para se incluir uma característica é preciso antes verificar se ela está relacionada a uma categoria que também está associada ao produto.
Para características do "tipo lista", "lista múltipla" e "lista tree", somente serão permitidos valores definidos na lista de opções destas características. Qualquer valor que não corresponda a um item da lista, será ignorado. É possível consultar as opções das listas das características em Consultar Características. Na consulta utilize o filtro "tipo" e "codigo" para facilitar a busca.
Características do tipo "lista múltipla" e "lista tree" esperam receber um array contendo os nomes das opções disponíveis.
Para as listas múltiplas, caso o valor dentro do array seja enviado como numérico (int) será buscada a opção pelo ID, ao invés do nome.
Este endpoint atualiza indiretamente todos os relacionamento de Produto X Características conforme as categorias do produto. Caso alguma categoria tenha sido desrelacionada do produto, os valores das características dessas categorias para o produto serão perdidos, pois o relacionamento Produto X Característica será desfeito.
