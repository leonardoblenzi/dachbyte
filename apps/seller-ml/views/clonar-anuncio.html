Mercado Livre assistido

Clone Mercado Livre pelo navegador, sem depender da API bloqueada.

O Mercado Livre bloqueia a leitura pelo servidor em muitos anuncios. Por isso, a mini extensao captura a pagina aberta no seu navegador e envia os dados reais para a Davantti montar o rascunho.

1.Arraste o botao azul para a barra de favoritos.
2.Abra o anuncio no Mercado Livre e clique no favorito.
3.Revise o rascunho criado na Davantti.
Mini extensao ML

Instale uma vez e clone direto da pagina do Mercado Livre

Este botao nao roda dentro da Davantti. Ele deve ficar na barra de favoritos do navegador para ser clicado quando voce estiver dentro do anuncio do Mercado Livre.

  1. Arraste Arraste para favoritos para a barra de favoritos.
  2. Entre no anuncio do Mercado Livre que deseja clonar.
  3. Clique no favorito Clonar na Davantti.
