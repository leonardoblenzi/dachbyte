DACHBYTE Seller Plataforma + Extensao

Politica de Privacidade da DACHBYTE Seller

Esta politica explica como a DACHBYTE coleta, usa, armazena e compartilha dados para operar a plataforma, seus modulos de gestao e a extensao DACHBYTE Seller Cloner.

Ultima atualizacao: 8 de maio de 2026.

1. Escopo desta politica

Esta pagina cobre o uso da plataforma DACHBYTE, incluindo modulos relacionados a Mercado Livre, Shopee, rastreio/logistica, SKU Leader, Madeira Madeira, publicidade, promocoes, margem, relatorios e automacoes operacionais.

Ela tambem cobre a extensao DACHBYTE Seller Cloner, usada para capturar dados de anuncios do Mercado Livre abertos pelo usuario no navegador e enviar essas informacoes para a DACHBYTE montar rascunhos de clonagem.

2. Dados que podemos coletar

Dependendo dos recursos utilizados, podemos coletar as seguintes informacoes:

  • Dados de cadastro, login e contato, como nome, e-mail, telefone, empresa, cargo e credenciais de acesso criptografadas ou tokens de sessao.
  • Dados de contas e integracoes autorizadas pelo usuario, como identificadores de contas, lojas, sellers, marketplaces, transportadoras e canais conectados.
  • Dados operacionais da sua conta, como anuncios, SKUs, produtos, pedidos, entregas, campanhas, promocoes, precos, custos, margens, visitas, cliques, investimento em publicidade e indicadores de desempenho.
  • Dados enviados em formularios, suporte ou contato comercial, incluindo mensagens, preferencias de plano e contexto informado pelo usuario.
  • Dados tecnicos, como endereco IP, user agent, data/hora de acesso, logs de erro, eventos de seguranca e informacoes necessarias para manter estabilidade da plataforma.

3. Dados coletados pela extensao DACHBYTE Seller Cloner

A extensao tem um unico proposito: permitir que usuarios autenticados capturem um anuncio do Mercado Livre aberto no navegador e criem um rascunho de clonagem dentro da DACHBYTE. Quando o usuario aciona esse recurso, a extensao pode coletar:

  • Token de sessao da extensao e identificador do usuario logado na DACHBYTE.
  • Conta/empresa selecionada para salvar o rascunho.
  • URL da aba ativa no momento da captura solicitada pelo usuario.
  • Dados publicos do anuncio capturado, como titulo, preco, imagens, descricao, categoria, atributos, identificador MLB e informacoes publicas do anuncio.
  • Logs tecnicos da captura, como data/hora, status da requisicao, mensagens de erro e dados de diagnostico.

A extensao nao coleta senhas do Mercado Livre, dados de pagamento, dados de saude, mensagens pessoais ou historico amplo de navegacao. A captura acontece somente quando o usuario solicita a acao de clonagem.

4. Como usamos os dados

Usamos os dados para finalidades ligadas ao funcionamento da DACHBYTE:

  • Autenticar usuarios, controlar acesso por conta e proteger a plataforma.
  • Sincronizar e exibir informacoes operacionais dos canais conectados.
  • Gerar paineis, tabelas, filtros, CSVs, relatorios, alertas e diagnosticos.
  • Criar, atualizar e exibir rascunhos de clonagem de anuncios.
  • Permitir que o usuario revise dados antes de executar qualquer acao sensivel, como publicacao, alteracao em massa ou remocao.
  • Prestar suporte, investigar falhas, prevenir abuso, melhorar estabilidade e evoluir recursos do produto.

Nao usamos dados da plataforma ou da extensao para venda de dados, publicidade comportamental, criacao de perfis para terceiros ou determinacao de credito.

5. Compartilhamento de dados

Nao vendemos, alugamos ou comercializamos dados dos usuarios. Podemos compartilhar ou processar dados somente quando necessario para operar a DACHBYTE, incluindo:

  • Fornecedores essenciais de hospedagem, banco de dados, monitoramento, seguranca, e-mail transacional e suporte tecnico.
  • Marketplaces, transportadoras, canais e integracoes conectadas pelo usuario, quando necessario para sincronizar, consultar ou executar a funcionalidade solicitada.
  • Autoridades, quando exigido por lei, ordem judicial ou para proteger direitos, seguranca e integridade da DACHBYTE, dos usuarios ou de terceiros.

6. Retencao e exclusao

Mantemos dados enquanto forem necessarios para prestar o servico, cumprir obrigacoes legais, resolver disputas, prevenir abusos, manter registros operacionais ou atender solicitacoes do usuario.

O usuario pode solicitar acesso, correcao ou exclusao de dados pessoais aplicaveis pelo canal de contato indicado nesta politica. Alguns logs e registros podem ser mantidos por prazo limitado por motivos de seguranca, auditoria e obrigacao legal.

7. Seguranca

Utilizamos conexoes HTTPS, autenticacao, controle de acesso por usuario e conta, segregacao de dados, registros de auditoria e praticas operacionais para reduzir riscos de acesso indevido, perda, alteracao ou divulgacao nao autorizada.

Nenhum sistema e absolutamente imune a riscos, mas trabalhamos para manter controles proporcionais ao tipo de dado tratado e a finalidade da plataforma.

8. Controle do usuario

O usuario pode, conforme disponibilidade tecnica e contratual:

  • Alterar dados de cadastro e preferencias de conta.
  • Revogar acessos, desconectar integracoes ou encerrar sessoes.
  • Revisar, remover ou descartar rascunhos de clonagem.
  • Solicitar informacoes sobre dados pessoais associados a sua conta.
  • Desinstalar a extensao DACHBYTE Seller Cloner pelo navegador Chrome.

9. Permissoes da extensao

A DACHBYTE Seller Cloner pode solicitar permissoes como acesso a aba ativa, execucao de script na pagina aberta, armazenamento local e comunicacao com dominios da DACHBYTE e do Mercado Livre. Essas permissoes sao usadas apenas para o recurso principal de captura assistida de anuncio e criacao de rascunho na DACHBYTE.

10. Uso limitado da Chrome Web Store

O uso de informacoes pela DACHBYTE Seller Cloner segue a Politica de Dados do Usuario da Chrome Web Store, incluindo os requisitos de Uso Limitado. Os dados acessados pela extensao sao usados somente para fornecer ou melhorar o recurso principal descrito nesta politica: capturar um anuncio por acao do usuario e enviar os dados para um rascunho de clonagem na DACHBYTE.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Nao permitimos leitura humana dos dados coletados pela extensao, exceto quando houver consentimento do usuario para suporte, quando for necessario para seguranca, para cumprir obrigacoes legais ou quando os dados estiverem agregados e anonimizados para operacoes internas.

11. Alteracoes nesta politica

Podemos atualizar esta politica para refletir mudancas no produto, nas integracoes, na legislacao ou em requisitos de lojas de extensoes. Quando houver alteracoes relevantes, atualizaremos a data desta pagina e, quando apropriado, comunicaremos os usuarios.
